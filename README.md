# 🎨 PicVerse

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

**PicVerse** adalah platform komunitas web interaktif yang dirancang khusus untuk para seniman digital. Platform ini menjadi ruang bagi para kreator untuk menemukan karya seni memukau, membagikan ilustrasi terbaik mereka, serta berinteraksi dengan sesama komunitas seniman.

---

## ✨ Fitur & Halaman utama

* 🏠 **Home Page:** Menampilkan *slideshow* karya pilihan, tag yang sedang tren, dan galeri karya unggulan (*featured artwork*).
* 🖼️ **Gallery Page:** Wadah eksplorasi untuk menjelajahi berbagai kumpulan karya seni digital.
* 📤 **Submission Page:** Formulir pengiriman karya interaktif bagi kreator yang ingin mengunggah ilustrasi mereka.
* 💬 **Community Page:** Ruang diskusi forum dan aktivitas terkini dari para anggota komunitas.
* ℹ️ **About Us Page:** Informasi mendalam mengenai visi, misi, fitur utama, dan kontak pengembang PicVerse.

---

## 🛠️ Teknologi yang Digunakan

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS tanpa framework/build process)
* **Assets:** Aset gambar dan font lokal yang tersimpan dalam direktori `asset/`

---

## 📁 Struktur Folder Proyek

```text
.

├── 📤 Submission-Page/      # Berkas untuk Halaman Pengiriman Karya
├── 💬 Community-Page/       # Berkas untuk Halaman Komunitas & Forum
├── ℹ️ About-Us-Page/        # Berkas untuk Halaman Tentang Kami

```

---

## 🚀 Cara Menjalankan Proyek

1. **Clone atau Unduh Repositori:**
   ```bash
   git clone https://github.com/username/PicVerse.git
   ```
2. **Buka Proyek:**
   Buka folder proyek menggunakan kode editor pilihan Anda (disarankan **Visual Studio Code**).
3. **Jalankan Aplikasi:**
   * **Opsi A (Rekomendasi):** Gunakan ekstensi **Live Server** di VS Code, klik kanan pada `Home-Page/Home-Page.html` lalu pilih *Open with Live Server*.
   * **Opsi B:** Buka berkas `Home-Page/Home-Page.html` secara langsung melalui peramban web (browser) Anda.
4. **Navigasi:** Gunakan bilah navigasi di bagian atas halaman untuk berpindah antarhalaman secara lancar.
